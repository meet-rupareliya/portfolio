# Meet Rupareliya — Portfolio

A single-page developer portfolio styled like a code editor (IDE theme), built with plain HTML, CSS & JS.

## Run it

Just open `index.html` in your browser. No build step, no dependencies.

## Features

- Code-editor style UI (tabs, file panels, line numbers, syntax colors)
- Dark / light theme toggle
- Sections: about, skills, certifications, activity log, projects, contact
- Fully responsive (mobile friendly)

## Tech

HTML · CSS · JavaScript
